Sobre la Aplicacion

Esta aplicación es un proyecto de ejemplo para demostrar el uso de Angular Universal con Server-Side Rendering (SSR). Utiliza la API pública de Pokémon para mostrar una lista de Pokémon y sus detalles. La aplicación está diseñada para ser rápida y eficiente, aprovechando las capacidades de SSR para mejorar el rendimiento y la experiencia del usuario.
